# Интерфейс IDE

Среда `kumir-ide` написана на `egui`/`eframe` и одинаково выглядит на Linux,
Windows и Android. Все иконки — векторные (SVG-подобные пути), эмодзи не
используются, поэтому интерфейс не зависит от шрифтов эмодзи.

## Основные области

| Область | Что находится |
|---|---|
| Верхнее меню | «Файл», «Правка», «Программа», «Вид», «Исполнитель», «Справка» |
| Панель инструментов | создать/открыть/сохранить, отменить/повторить, запуск/остановка/пауза/шаг, проверка, оценка, точка останова, поиск, исполнитель, настройки |
| Слева | проводник `.kum`, `.fil`, `.kod` и список недавних файлов |
| По центру | вкладки редактора, строка поиска, сам редактор с номерами строк и подсветкой |
| Справа | «Структура» программы (алгоритмы, глобальные величины, переменные, точки останова) и «Исполнитель» |
| Снизу | «Вывод», «Ошибки», «Упоминания», «Справка» |
| Статус | сообщение, позиция курсора, язык, кодировка, имя файла |

Панели можно скрывать через меню «Вид»; размеры боковых и нижней панелей
задаются перетаскиванием их границ.

## Редактор

* подсветка синтаксиса, номера строк, подсветка текущей строки;
* **автоотступ**: Enter после `алг`, `нач`, `нц`, `если … то`, `выбор`,
  `при …:` добавляет уровень отступа; `кц`, `все`, `кон` выравниваются
  автоматически (настройка «Автоотступ»);
* Tab и Shift+Tab — отступ и снятие отступа у выделенных строк;
* **автодополнение**: список ключевых слов, типов, стандартных функций,
  алгоритмов, переменных и команд исполнителей. `Ctrl+Space` — полный список,
  Enter/Tab — вставить, Esc — закрыть;
* **подсказка-призрак**: серый хвост лучшего совпадения после курсора, Tab
  принимает его. Отключается в настройках («Подсказка-призрак»);
* внутри аргументов вызова показывается сигнатура алгоритма или команды
  исполнителя с номером текущего аргумента;
* контекстное меню (правая кнопка мыши, на Android — долгое нажатие):
  копировать/вырезать/вставить, перейти к определению, найти упоминания,
  переименовать, справка по слову, закомментировать, дублировать строку,
  переместить строку, форматировать отступы, вставить шаблон;
* внутренняя отмена/повтор (Ctrl+Z / Ctrl+Y) на 300 шагов;
* несохранённые вкладки помечаются точкой; при закрытии IDE предлагает
  сохранить изменения.

Файлы открываются в UTF-8 (с BOM или без) и Windows-1251; скрытые и
защищённые учительские строки `|@hidden` / `|@protected` сохраняются.

## Цветовые схемы

В настройках («Вид → Настройки → Вид») есть готовые схемы:

* Тёмная;
* Светлая;
* Высокий контраст;
* Океан;
* Сепия;
* **Своя схема** — редактор цветов всех ролей интерфейса и подсветки.

Свою схему можно экспортировать в текст и импортировать обратно
(`акцент=#5c9eff` и т.п.). Настройки и схема сохраняются в
`kumir.conf`:

| Система | Путь |
|---|---|
| Linux | `$XDG_CONFIG_HOME/kumir/kumir.conf` или `~/.config/kumir/kumir.conf` |
| Windows | `%APPDATA%\Kumir\kumir.conf` |
| Android | внутренний каталог приложения `config/kumir.conf` |

| Клавиши | Действие |
|---|---|
| `F5` | запустить программу |
| `Shift+F5` | остановить |
| `F6` | пауза / продолжить |
| `F10` | шаг |
| `F9` | точка останова на текущей строке (или клик по номеру строки) |
| `F7` | показать исполнителя |
| `F8` / `Shift+F8` | следующая / предыдущая ошибка |
| `F12` | перейти к определению |
| `F1` | справка (контекстная — по слову под курсором) |
| `Ctrl+N`, `Ctrl+O` | новый / открыть файл |
| `Ctrl+S`, `Ctrl+Shift+S` | сохранить / сохранить как |
| `Ctrl+W`, `Ctrl+Q` | закрыть вкладку / выйти |
| `Ctrl+Z`, `Ctrl+Y` | отменить / повторить |
| `Ctrl+X`, `Ctrl+C`, `Ctrl+V`, `Ctrl+A` | вырезать, копировать, вставить, выделить всё |
| `Ctrl+F` | найти и заменить |
| `Ctrl+G` | перейти к строке |
| `Ctrl+P` | быстрый переход к файлу |
| `Ctrl+B` | проверить синтаксис |
| `Ctrl+/` | закомментировать строки |
| `Ctrl+D` | дублировать строку |
| `Alt+↑`, `Alt+↓` | переместить строку |
| `Ctrl+Shift+I` | форматировать отступы |
| `Ctrl+Space` | список подсказок |
| `Ctrl+=`, `Ctrl+-` | увеличить / уменьшить шрифт |

## Запуск и отладка

Запуск выполняется в фоновом потоке, вывод поступает в панель «Вывод».
Если панель была скрыта, при запуске она **не открывается** (настройка
«Открывать панель „Вывод“ при запуске», по умолчанию выключена). Ошибки
показываются бейджем и в панели «Ошибки», если включена настройка
«Открывать панель „Ошибки“ при ошибке».

* ввод с консоли — строка «Ввод:» в панели вывода; если панель скрыта,
  программа ждёт ввода, а в панели инструментов появляется кнопка
  «Программа ждёт ввода»;
* пауза, шаг и точки останова подсвечивают текущую строку;
* при паузе в структуре показываются значения переменных;
* «Оценить» запускает скрытый алгоритм `@тестирование` и выводит оценку
  (`@поставить оценку`).

## Исполнители

Панель справа показывает активных исполнителей; если их несколько
(`использовать Робот` и `использовать Черепаха`), между ними переключают
вкладки. Пульт позволяет выдавать команды вручную, а кнопка
«Вставить протокол» переносит команды пульта в программу как текст Kumir.
Файлы заданий: `.fil` (Робот), `.vod` (Водолей), `.kz` (Кузнечик), `.png`
(Рисователь), `.svg` (экспорт рисунка Черепахи и Чертежника).

## Android

* панели автоматически уплотняются, проводник скрыт по умолчанию;
* **выделение текста**: коснитесь редактора, затем перетаскивайте маркеры;
  над выделением появляется панель «Вырезать / Копировать / Вставить /
  Выделить всё / Комментарий / Определение / Ещё / Запуск»;
* **долгое нажатие** открывает то же контекстное меню, что и правая кнопка
  мыши на компьютере, и выделяет слово под пальцем;
* системный буфер обмена Android доступен для копирования и вставки;
* меню и кнопки увеличены для пальца; масштаб интерфейса меняется щипком
  или в настройках;
* клавиатура не перезапускается при каждом клике, а Enter вставляет
  новую строку с автоотступом.

## Справка

`F1` открывает окно справки с разделами «Язык Кумир», «Исполнители»,
«Интерфейс и клавиши», «Сборка и установка». Внизу окна — поиск по всем
разделам; по слову под курсором (`F1` или «Справка по слову» в контекстном
меню) открывается нужный раздел. Примеры кода можно скопировать одной
кнопкой.

На Android над редактором есть панель символов (:=, скобки, кавычки, `нс`,
Tab, снятие отступа, отмена/повтор): она помогает вводить код без
переключения раскладки.
