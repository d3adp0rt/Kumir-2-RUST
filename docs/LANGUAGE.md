# Язык Кумир — справка

Краткая справка для IDE. Полное описание переноса — [PORTING.md](PORTING.md).

В редакторе работает автодополнение: начните вводить слово (2+ буквы) или
нажмите `Ctrl+Space`; `↑`/`↓` — выбор, `Enter`/`Tab` — вставка,
`Esc` — закрыть.

## Программа

```
алг Имя алгоритма
нач
    ...
кон
```

Первый алгоритм файла — главный, даже если у него есть имя.

```
алг цел Удвоить(цел x)
нач
    знач := 2 * x
кон
```

## Типы

`цел`, `вещ`, `лит`, `сим`, `лог`, `файл`.

Массивы: `целтаб A[1:10]`, `вещтаб M[1:3, 1:4]`.
Индексация — с 1. Инициализация: `целтаб A[1:3] = {1, 2, 3}`.

## Операторы

| Оператор | Значение |
|---|---|
| `:=` | присваивание |
| `+ - * /` | арифметика |
| `**` | степень |
| `= <> < > <= >=` | сравнения |
| `и`, `или`, `не` | логика |
| `div`, `mod` | целочисленное деление и остаток |

## Ввод/вывод

```
ввод a, b
вывод a, ' ', b, нс
вывод x:8:3        | ширина 8, 3 знака после точки
```

Строка при `ввод s` читается целиком до конца строки.

## Условия

```
если условие то
    ...
иначе
    ...
все
```

```
выбор
при x = 1: вывод "один"
при x = 2: вывод "два"
иначе     вывод "нет"
все
```

## Циклы

```
нц для i от 1 до 10 шаг 2
    ...
кц

нц пока условие
    ...
кц

нц 5 раз
    ...
кц

нц
    ...
кц при условие
```

`выход` прерывает цикл; вне цикла — возвращает управление из алгоритма.
`пауза` останавливает до нажатия «Продолжить», `стоп` завершает программу.

## Параметры

```
алг Процедура(арг цел x, рез цел y, аргрез лит s)
```

* `арг` — только вход (по значению);
* `рез` — только выход;
* `аргрез` — вход и выход.

Массивы передаются по значению для `арг` и по ссылке для `рез`/`аргрез`.

## Строки

```
лит s = 'привет'
s[1]        | символ
s[1:3]      | подстрока включительно
длин(s)
код(s[1])
символ(65)
```

`arcctg`, `exp`, `ln`, `lg`, `min`, `max`, `imin`, `imax`, `sign`, `int`,
`div`, `mod`, `rnd`, `irnd`, `rand`, `irand`, `время`, `ждать`,
`МАКСВЕЩ`, `МАКСЦЕЛ`, `длин`, `код`, `символ`, `юникод`, `юнисимвол`,

## Файлы

```
использовать Файлы
...
файл f
f := открыть на чтение('input.txt')
нц пока не конец файла(f)
    ввод f, x
кц
закрыть(f)

g := открыть на запись('output.txt')
вывод g, x, нс
закрыть(g)
```

## Строки (модуль)

```
использовать Строки
позиция(фрагмент, s)
позиция после(от, фрагмент, s)
вставить(фрагмент, s, позиция)
удалить(s, начало, количество)
заменить(s, старый, новый, да)
верхний регистр(s)
нижний регистр(s)
```

## Имена из нескольких слов

```
цел число проходов по таблицам
число проходов по таблицам := 0
```

## Модули

```
использовать Файлы
использовать Строки
использовать Робот
использовать "библиотека.kum"
```

Локальный модуль ищется как `Имя.kum` рядом с программой.
