# Язык Кумир — справочник

Полное описание языка, которое понимает `kumir-core`.  Справка в IDE
открывается по `F1` и содержит этот же текст.

## Программа

```
алг Имя алгоритма
нач
    ...
кон
```

Первый алгоритм файла — главный, даже если у него есть имя.  Если у
главного алгоритма указан тип результата, он не используется.

```
алг цел Удвоить(цел x)
нач
    знач := 2 * x
кон
```

Перед первым алгоритмом могут стоять `использовать …` и объявления
глобальных величин.

## Ключевые слова

`исп`/`модуль`, `кон_исп`, `использовать`, `ВКЛЮЧИТЬ`, `алг`, `нач`,
`кон`, `дано`, `надо`, `утв`, `нц`, `кц`, `кц_при`, `для`, `раз`/`раза`,
`пока`, `от`, `до`, `шаг`, `выход`, `если`, `то`, `иначе`, `все`/`всё`,
`выбор`, `при`, `ввод`, `вывод`, `нс`, `не`, `и`, `или`, `арг`, `рез`,
`аргрез`, `знач`, `да`, `нет`, `файл`, `пауза`, `стоп`, `НАЗНАЧИТЬ`.

Английские варианты (`algorhitm`, `begin`, `end`, `if`, `then`, `else`,
`done`, `while`, `for`, `times`, `do`, `end_do`, `use`, `scan`, `print`,
`endl`, `not`, `and`, `or`, `int`, `real`, `string`, `char`, `bool`) также
принимаются.  Наличие кириллицы в файле включает русский набор символов.

## Типы

| Тип | Значения |
|---|---|
| `цел` | целые числа |
| `вещ` | вещественные числа |
| `лог` | `да` / `нет` |
| `сим` | один символ |
| `лит` | строка |
| `файл` | дескриптор файла (модуль «Файлы») |

Массивы: `целтаб A[1:10]`, `цел таб B[1:3, 1:4]`, `вещтаб M[1:5]`,
`литтаб`, `симтаб`, `логтаб`.  Индексация с 1.  Инициализация:
`целтаб A[1:3] = {1, 2, 3}`.

Переменные объявляются в любом месте тела; в одном объявлении тип может
меняться: `файл f, вещ x, y`.

Имена могут состоять из нескольких слов:

```
цел число проходов по таблицам
число проходов по таблицам := 0
```

## Операторы

| Оператор | Значение |
|---|---|
| `:=` | присваивание |
| `+ - * /` | арифметика; `/` всегда даёт `вещ` |
| `**` | степень (для целых неотрицательных — `цел`) |
| `= <> < > <= >=` (`≤ ≥ ≠`) | сравнения |
| `и`, `или`, `не` | логика |
| `div`, `mod` | целочисленное деление и остаток |

`div` округляет вниз, `mod` всегда неотрицателен: `-7 div 2 = -4`,
`-7 mod 2 = 1`.

## Ввод и вывод

```
ввод a, b
вывод a, ' ', b, нс
вывод x:8:3        | ширина 8, 3 знака после точки
вывод x:-8:3       | выравнивание влево
```

* `нс` — перевод строки;
* строки и символы — в одинарных или двойных кавычках;
* `ввод s` для строки читает всю строку;
* логические значения выводятся как `да`/`нет`;
* вещественные — до 13 значащих цифр, экспонента при |x| < 10⁻⁴ или ≥ 10⁶,
  хвостовые нули убираются (`12.0` выводится как `12.0`).

## Условия

```
если a > b то
    ...
иначе
    ...
все
```

```
выбор
при x = 1: вывод "один"
при x = 2: вывод "два"
иначе     вывод "нет"
все
```

Двоеточие в `при` необязательно; `иначе` может быть в одну строку.

## Циклы

```
нц для i от 1 до 10 шаг 2
    ...
кц

нц пока a > 0
    ...
кц

нц 5 раз
    ...
кц

нц
    ...
кц при a = 0
```

`нц … кц` без условия — бесконечный цикл (выход через `выход`).
`выход` прерывает цикл, а вне цикла завершает алгоритм.  `пауза`
останавливает программу до «Продолжить», `стоп` завершает выполнение.

## Алгоритмы и параметры

```
алг Процедура(арг цел x, рез цел y, аргрез лит s)
нач
    y := x * 2
    s := s + "!"
кон
```

* `арг` — только вход (по значению);
* `рез` — только выход;
* `аргрез` — вход и выход;
* запись `арг рез` с пробелом допустима;
* результат функции возвращается присваиванием `знач := …`;
* массивы передаются по значению для `арг` и по ссылке для `рез`/`аргрез`.

## Массивы и строки

```
целтаб A[1:10]
A[1] := 5
вывод A[1]

лит s = 'привет'
вывод s[1]       | символ
вывод s[1:3]     | подстрока включительно
s[1] := 'П'
```

Срезы массивов как lvalue не поддерживаются (как и в оригинале).

`abs`, `iabs`, `sqrt`, `sin`, `cos`, `tg`, `ctg`, `arcsin`, `arccos`,
`arctg`, `arcctg`, `exp`, `ln`, `lg`, `min`, `max`, `imin`, `imax`,

`irand(a, b)`, `время`, `ждать(мс)`, `МАКСВЕЩ`, `МАКСЦЕЛ`.

Строки: `длин`, `код`, `символ`, `юникод`, `юнисимвол`, `цел_в_лит`,

```
x := лит_в_цел('12', ok)     | ok = да
```

## Модули

```
использовать Файлы
использовать Строки
использовать Робот
использовать "библиотека.kum"
```

Встроенные модули: `Файлы`, `Строки`, `Робот`, `Черепаха`, `Чертежник`,
`Водолей`, `Кузнечик`, `Рисователь` (а также английские `Files`,
`String Utilities`, `Robot`, `Turtle`, `Draw`, `Vodoley`, `Grasshopper`,
`Painter`).  Пользовательский модуль ищется как `Имя.kum` рядом с
программой; его глобальные величины, инициализатор и алгоритмы
добавляются к программе.  `ВКЛЮЧИТЬ "файл"` вставляет текст файла.

### Файлы

```
использовать Файлы
файл f
f := открыть на чтение('input.txt')
нц пока не конец файла(f)
    ввод f, x
кц
закрыть(f)

g := открыть на запись('output.txt')
вывод g, x, нс
закрыть(g)
```

Функции: `открыть на чтение`, `открыть на запись`, `открыть на добавление`,
`закрыть`, `начать чтение`, `конец файла`, `есть данные`,
`установить кодировку`, `можно открыть на чтение`, `можно открыть на запись`,
`существует`, `существует файл`, `является каталогом`, `создать каталог`,
`создать файл`, `полный путь`, `удалить_файл`, `удалить_каталог`,
`РАБОЧИЙ КАТАЛОГ`, `КАТАЛОГ ПРОГРАММЫ`, `консоль`.

Кодировка по умолчанию — UTF-8; `установить кодировку('cp1251')`
включает Windows-1251.

## Исполнители

Команды исполнителей описаны в [ACTORS.md](ACTORS.md).  Их можно писать
со скобками и без них:

```
вперед(10)
вперед 10
наполни B
перелей из B в A
```

Команда, не подключённая к программе, — ошибка выполнения с подсказкой,
какой модуль добавить.

## Учительские маркеры `.kum`

* `|@hidden` в конце строки — скрытая (учительская) строка;
* `|@protected` — защищённая строка видимой части;
* `|@signature …` — подпись скрытого текста (сохраняется, не проверяется).

При компиляции скрытый текст добавляется к видимому; при сохранении
маркеры остаются на своих местах.  Файлы читаются в UTF-8 (с BOM или без)
и Windows-1251, записываются в UTF-8 с сохранением BOM.

## Отличия от КуМир 2

* нет статической проверки типов: ошибки типов возникают при выполнении;
* пользовательские записи и перечисления, кроме `файл`, не поддерживаются;
* тип-запись `цвет` заменён строкой/числом;
* `.kod` (байткод старой VM) не исполняется — используйте `.kum`.
