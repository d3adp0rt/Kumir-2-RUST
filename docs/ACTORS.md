# Исполнители

Реализованы все шесть исполнителей КуМир 2: **Робот**, **Черепаха**,
**Чертежник**, **Водолей**, **Кузнечик** и **Рисователь**.  Можно подключить
несколько исполнителей одновременно — как в оригинальной среде:

```
использовать Робот
использовать Черепаха
```

В панели «Исполнитель» между ними переключают вкладки.  У каждого
исполнителя есть **пульт** (ручное управление) и **протокол**: кнопка
«Вставить протокол» переносит выполненные команды в программу как обычный
текст Кумира.

Состояние всех исполнителей хранится в `crates/kumir-core/src/actors/`,
описание команд — в `commands.rs`, отрисовка — в `kumir-gui/src/app.rs`.

Если рядом с открытой программой лежит файл задания с тем же именем
(`<программа>.fil`, `.vod`, `.kz`), он подхватывается автоматически.

## Цвет

Чертежник, Черепаха и Рисователь принимают цвет в любом из форматов
оригинального модуля `_Colorer`:

* русские названия: `черный`, `белый`, `серый`, `фиолетовый`, `синий`,
  `голубой`, `зеленый`, `желтый`, `оранжевый`, `красный`, `прозрачный`;
* имена W3C: `red`, `navy`, `darkorange`, …;
* `#RGB`, `#RGBA`, `#RRGGBB`, `#RRGGBBAA`;
* функции `rgb(r, g, b)`, `rgba(r, g, b, a)`, `hsl(h, s, l)`, `hsla`,
  `hsv`, `hsva`, `cmyk(c, m, y, k)`, `cmyka`;
* число — цвет `#RRGGBB`;
* пустая строка `''` — прозрачный цвет (для кисти — «без заливки»).

Доступны функции цвета: `RGB`, `RGBA`, `HSL`, `HSLA`, `HSV`, `HSVA`,
`CMYK`, `CMYKA` и `разложить в RGB/CMYK/HSL/HSV(цвет, рез …)`.

## Робот

```
использовать Робот
```

Поле — прямоугольник 1–255 столбцов и 1–128 строк, окружённый «забором».
Клетка хранит стены, закраску, радиацию (0…99), температуру (−273…233),
два символа и учительскую метку.  Позиция Робота в `.fil` — стартовая; при
запуске Робот возвращается в неё, а стены, цвета и метки сохраняются.

Панель «Исполнитель» позволяет:

* менять размер поля, открывать и сохранять `.fil`;
* редактировать поле: инструменты «Цвет», «Стена», «Метка», «Робот»,
  «Сдвиг»; отмена/повтор (Ctrl+Z / Ctrl+Y); «Снять закраску», «Очистить»,
  «Робот на старт», «До запуска»;
* масштабировать колесом и перетаскивать; двойной клик — сброс;
* видеть красную рамку поля в режиме редактирования;
* при столкновении Робот считается разбившимся, а выполнение прерывается
  с сообщением о стене.

### Команды

| Команда | Результат |
|---|---|
| `вверх`, `вниз`, `влево`, `вправо` | шаг на клетку; стена — ошибка выполнения |
| `закрасить` | закрасить текущую клетку |
| `сверху стена`, `снизу стена`, `слева стена`, `справа стена` | проверка стены |
| `сверху свободно`, `снизу свободно`, `слева свободно`, `справа свободно` | проверка отсутствия стены |
| `клетка закрашена`, `клетка чистая` | состояние текущей клетки |
| `радиация` | `вещ`, радиация текущей клетки |
| `температура` | `цел`, температура текущей клетки |

Стены читаются с обеих сторон: если в `.fil` стена записана только у одной
из двух соседних клеток, она всё равно считается стеной.

### Служебные функции (для скрытых учительских алгоритмов)

| Функция | Результат |
|---|---|
| `@@размер поля(рез строк, рез столбцов)` | размеры поля |
| `@@робот(рез строка, рез столбец)` | позиция Робота, от 1 |
| `@@метка(строка, столбец)` | `лог`, есть ли метка |
| `@@закрашена(строка, столбец)` | `лог`, закрашена ли клетка |
| `@@верхняя буква(строка, столбец)` | `сим`, `Symbol` из `.fil` |
| `@@нижняя буква(строка, столбец)` | `сим`, `Symbol1` из `.fil` |
| `@@температура(строка, столбец)` | `цел` |
| `@@радиация(строка, столбец)` | `вещ` |

Номера строк и столбцов — **от 1**, как в учительских задачах.  Внутри
поля координаты 0-based, Y растёт вниз.

### Формат `.fil`

```
; Field Size: x, y
5 2
; Robot position: x, y
0 0
; A set of special Fields: x, y, Wall, Color, Radiation, Temperature, Symbol, Symbol1, Point
0 0 0 0 0.000000 0 А $
0 1 8 0 0.000000 0 $ Б
1 1 8 0 0.000000 0 $ $
; End Of File
```

* первые две строки без `;` — размер и стартовая позиция;
* далее по строке на клетку: `x y walls color radiation temperature symbol symbol1 point`;
* `walls`: `1` слева, `2` справа, `4` снизу, `8` сверху;
* `color`: `0`/`1`; `point`: `1`/`0` — учительская метка;
* `$` — пустой символ;
* записываются только непустые клетки (как в оригинале);
* файлы читаются в UTF-8 или Windows-1251.

## Черепаха

```
использовать Черепаха
```

Старт — в центре арены 500×500, хвост опущен, направление — вверх.
По умолчанию (как в пособии) арена окружена «рвом с водой»: если конец
хвоста должен выйти за арену, исполнитель отказывает.  В настройках
(«Выполнение → Черепаха») можно выбрать режим **«Без границ»** — тогда
рисовать можно где угодно.

| Команда | Действие |
|---|---|
| `поднять хвост`, `опустить хвост` | перо |
| `вперед(d)`, `назад(d)` | проползти `d` единиц (1 единица = 1 пиксель) |
| `влево(a)`, `вправо(a)` | поворот на `a` градусов |
| `выбрать чернила(c)` | цвет пера |

Рисунок можно сохранить в SVG кнопкой в панели исполнителя.

## Чертежник

```
использовать Чертежник
```

| Команда | Действие |
|---|---|
| `опустить перо`, `поднять перо` | перо |
| `выбрать чернила(c)`; `установить цвет(c)` | цвет пера (второе имя — из пособия) |
| `сместиться в точку(x, y)` | абсолютное перемещение |
| `сместиться на вектор(dx, dy)` | относительное перемещение |
| `написать(ширина, текст)`; `надпись(ширина, текст)` | подпись; перо переходит к правому нижнему краю текста |
| `@есть отрезок в области(x, y, радиус)` | `лог`, есть ли отрезок в круге |

Ширина символа задаётся в условных единицах чертежника; координаты —
декартовы, Y растёт вверх.  Рисунок экспортируется в SVG.

## Водолей

```
использовать Водолей
```

Три сосуда A, B, C с целыми объёмами.  В сосуде C объём может быть 0 —
тогда он не показывается.  Цель — получить в одном из сосудов заданное
количество воды.

| Команда | Действие |
|---|---|
| `наполни A`, `наполни B`, `наполни C` | долить сосуд доверху |
| `вылей A`, `вылей B`, `вылей C` | вылить всё |
| `перелей из A в B` (и остальные пять пар) | перелить до полного или до опустошения |
| `@решено` | `лог`, есть ли нужное количество в каком-либо сосуде |
| `размер A`, `размер B`, `размер C` | `цел`, объём сосуда |
| `в сосуде A`, `в сосуде B`, `в сосуде C` | `цел`, сколько воды сейчас |

Задание редактируется в панели исполнителя (ёмкости, начальное наличие,
требуемое количество) и сохраняется в `.vod`:

```
;Capacity
3 5 7
;Fullness
0 0 0
;Need
1 1 1
```

## Кузнечик

```
использовать Кузнечик
```

Живёт на числовой прямой.  В задании задаются длины прыжков вперёд и назад,
стартовая точка, границы (необязательно) и флажки (необязательно).
Флажки не мешают прыгать; они только отмечают точки.  Границы
`−1000…1000` или шире означают «без границ».

| Команда | Действие |
|---|---|
| `вперед(n)` | прыжок вперёд; `n` должен совпадать с длиной прыжка задания |
| `назад(n)` | прыжок назад |
| `перекрасить` | закрасить текущую точку |

Команды можно писать и без скобок, как в пособии: `вперед 3`, `назад 2`.
Выход за границы и неверная длина прыжка — ошибки выполнения.

Задание сохраняется в `.kz`:

```
;Step forward Step Back
3 5
;StartPos
0
;Left border Right border
-1024 1024
;Flags
3 7
;END
```

## Рисователь

```
использовать Рисователь
```

Лист по умолчанию 640×480, белый.  Перо и кисть задают контур и заливку.
Текст хранится отдельными элементами и рисуется IDE; команда
`ширина текста` использует детерминированную оценку ширины (оригинал
брал метрики системного шрифта).

| Команда | Действие |
|---|---|
| `перо(толщина, цвет)` | толщина и цвет контура; толщина 0 — без контура |
| `кисть(цвет)`, `убрать кисть` | цвет и режим заливки |
| `шрифт(название, размер, жирный, курсив)` | параметры текста |
| `в точку(x, y)` | переместить перо |
| `линия в точку(x, y)` | линия из текущей точки |
| `линия(x1, y1, x2, y2)` | отрезок |
| `прямоугольник(x1, y1, x2, y2)` | контур и заливка прямоугольника |
| `эллипс(x1, y1, x2, y2)` | эллипс, вписанный в прямоугольник |
| `окружность(x, y, r)` | окружность/круг |
| `многоугольник(N, X, Y)` | многоугольник по таблицам координат |
| `надпись(x, y, текст)` | текст, левый верхний угол |
| `залить(x, y)` | залить связную область цветом кисти |
| `пиксель(x, y, цвет)` | поставить пиксель |
| `значение в точке(x, y)` | `цвет` пикселя |
| `новый лист(ширина, высота, фон)` | новый лист (не меньше 20×20) |
| `загрузить лист(имя)`, `сохранить лист(имя)` | PNG |
| `высота листа`, `ширина листа`, `центр x`, `центр y` | размеры листа |
| `ширина текста(текст)` | ширина надписи в пикселях |
| `плотность(n)` | совместимость: сохраняется, на рисунок не влияет |

Координаты — экранные: (0,0) в левом верхнем углу, Y растёт вниз.

> Примечание: текст Рисователя хранится отдельными элементами и рисуется
> IDE.  При сохранении в PNG надписи не растрируются — переносите их
> средствами графического редактора, если нужен «плоский» файл.

## Запуск с проверкой

1. Откройте `.kum` задания (скрытый `@тестирование` уже внутри).
2. При необходимости загрузите поле/задание: «Исполнитель → …».
3. Напишите решение в видимой части.
4. Нажмите «Оценить» (или `kumir-run --evaluate --field field.fil task.kum`).

В режиме оценки главный алгоритм отдельно не запускается: точкой входа
становится `@тестирование`, который сам вызывает решение ученика и
проверяет поле.  Оценка выводится как `=== Оценка: N из 10 ===` и
сохраняется в `RunOutcome::mark`.

## Не перенесено

* «Клавиатура», изометрический Робот и комплексные числа;
* тип-запись `цвет` из `_Colorer` (цвета задаются строкой/числом);
* анимация поворотов и звуки Qt-исполнителей.
