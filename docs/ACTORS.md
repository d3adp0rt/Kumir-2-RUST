# Исполнители

Реализованы три исполнителя: **Робот**, **Черепаха** и **Чертежник**.
Состояние хранится в `crates/kumir-core/src/actors.rs`, отрисовка — в
`crates/kumir-gui/src/app.rs` (панель «Исполнитель»).

## Робот

Подключение:

```
использовать Робот
```

При открытии программы с `использовать Робот` автоматически подхватывается
поле `имя_программы.fil`, если оно лежит рядом. Панель «Исполнитель»
находится справа (вкладка рядом со «Структурой») и открывается сама при
запуске программы с исполнителем.

Размер поля задаётся там же: поля «ширина × высота» и
кнопка «Применить размер» (по умолчанию 7×7). Там же можно загрузить готовое поле
`.fil`, сохранить текущее поле и включить редактирование:

* колесо мыши — масштаб, перетаскивание — сдвиг, двойной клик — сброс;
* «✎ Редактировать поле» включён по умолчанию для поля Робота; режим
  виден по акцентной рамке поля и бейджу «✎ РЕДАКТИРОВАНИЕ ПОЛЯ» в углу
  (без перекрывающей надписи по центру);
  изменения применяются сразу (отдельной кнопки «применить расстановку»
  не нужно). Инструменты:
  * 🎨 **Цвет** — закрасить/очистить клетку, можно рисовать перетаскиванием;
  * 🧱 **Стена** — поставить/убрать стену; при наведении показывается
    полупрозрачный «призрак» стены, стена автоматически дублируется у
    соседней клетки;
  * 📍 **Метка** — поставить/снять учительскую метку `Point`;
  * 🤖 **Робот** — поставить робота; робота можно перетаскивать мышью
    и без режима редактирования;
  * ✋ **Сдвиг** — панорамирование в режиме редактирования;
* кнопки ↶ / ↷ и Ctrl+Z/Ctrl+Y — отмена и повтор изменений поля;
* Shift+ЛКМ или ПКМ — быстро поставить/снять метку;
* **«Снять закраску»** — убрать только цвета, сохранив стены, метки и символы;
* **«Очистить всё»** — сбросить цвета, стены, метки и символы;
* **«Робот на старт»** — вернуть Робота в стартовую клетку;
* **«⟲ До последнего запуска»** — полностью вернуть поле к состоянию,
  которое было непосредственно перед последним запуском (стены, цвета,
  метки, символы, размер и позицию Робота). Если запуска ещё не было,
  кнопка называется «⟲ Исходное поле» и возвращает поле к моменту
  загрузки/создания;
* «💾 Сохранить .fil» — записать поле в формате оригинала
  (позиция робота сохраняется как стартовая);
* расстановка сохраняется между запусками: при запуске сбрасывается
  только позиция Робота на стартовую, а стены, цвета и метки остаются;
* всё, что изменил последний запуск (закраска, перемещение Робота),
  можно полностью откатить кнопкой «⟲ До последнего запуска».

Из командной строки используйте `--field-size 9x7`, `--field field.fil`
и `--actor-delay 30`. Внутренние координаты
0-based, ось Y направлена **вниз** (как в `.fil` и на экране): `вниз`
увеличивает Y, `вверх` уменьшает. В IDE можно открыть поле `.fil`.

Команды:

| Команда | Действие |
|---|---|
| `вверх`, `вниз`, `влево`, `вправо` | шаг на клетку; стена/граница — ошибка выполнения |
| `закрасить` | закрасить текущую клетку |
| `сверху стена`, `снизу стена`, `слева стена`, `справа стена` | проверка стены |
| `сверху свободно`, `снизу свободно`, `слева свободно`, `справа свободно` | проверка отсутствия стены |
| `клетка закрашена`, `клетка чистая` | состояние клетки |
| `радиация`, `температура` | значения текущей клетки |

Служебные функции (используются скрытыми учительскими алгоритмами):

| Функция | Результат |
|---|---|
| `@@размер поля(рез строк, рез столбцов)` | размеры поля |
| `@@робот(рез строка, рез столбец)` | позиция робота (1-based) |
| `@@метка(строка, столбец)` | есть ли в клетке символ |
| `@@закрашена(строка, столбец)` | закрашена ли клетка |
| `@@верхняя буква(строка, столбец)` | `Symbol` из `.fil` |
| `@@нижняя буква(строка, столбец)` | `Symbol1` из `.fil` |
| `@@температура`, `@@радиация` | значения клетки |

Номера строк/столбцов в `@@`-функциях — **1-based** (как в скрытых
учительских алгоритмах: циклы идут `от 1 до строк`). Внутри поля
координаты 0-based, преобразование выполняет интерпретатор.

## Черепаха

```
использовать Черепаха
```

Старт: (0, 0), угол 90° (вверх), перо опущено.

| Команда | Действие |
|---|---|
| `поднять хвост`, `опустить хвост` | перо |
| `вперед(d)`, `назад(d)` | движение |
| `влево(a)`, `вправо(a)` | поворот на `a` градусов |
| `выбрать чернила(c)` | цвет (`'red'`, `'#ff8800'`, число) |

## Чертежник

```
использовать Чертежник
```

| Команда | Действие |
|---|---|
| `опустить перо`, `поднять перо` | перо |
| `выбрать чернила(c)` | цвет |
| `сместиться в точку(x, y)` | перемещение |
| `сместиться на вектор(dx, dy)` | относительное перемещение |
| `написать(ширина, текст)` | подпись в текущей точке |

## Формат `.fil`

Текстовый файл:

```
; Field Size: x, y
5 2
; Robot position: x, y
0 0
; A set of special Fields: x, y, Wall, Color, Radiation, Temperature, Symbol, Symbol1, Point
0 0 0 0 0.000000 0.000000 А $
0 1 8 0 0.000000 0.000000 $ Б
1 1 8 0 0.000000 0.000000 $ $
2 1 8 0 0.000000 0.000000 $ $
3 1 8 0 0.000000 0.000000 $ $
; End Of File
```

* первые две строки без `;` — размер и позиция робота;
* далее по строке на клетку: `x y walls color radiation temperature symbol symbol1`;
* `walls` — битовая маска: `1` слева, `2` справа, `4` снизу, `8` сверху;
* `color` — `0`/`1`;
* `$` — пустой символ;
* последняя колонка `Point` — учительская метка (`1`/`0`), её проверяет
  `@@метка`;
* координаты 0-based, Y растёт вниз.

Файлы читаются в UTF-8 или Windows-1251.

## Как запустить задание с проверкой

1. Откройте `.kum` задания (скрытый `@тестирование` уже внутри файла).
2. При необходимости загрузите поле: «Исполнитель → Открыть поле Робота (.fil)».
3. Напишите решение в видимой части.
4. Нажмите «🎓 Оценить» (или `kumir-run --evaluate --field field.fil task.kum`).

В режиме оценки главный алгоритм отдельно не запускается: точкой входа
становится `@тестирование`, который сам вызывает решение ученика и
проверяет поле. Оценка выводится в консоль как
`=== Оценка: N из 10 ===` и сохраняется в `RunOutcome::mark`.

## Ограничения

* нет анимации, поворотов и звуков оригинальных Qt-исполнителей;
* Рисователь, Водолей, Кузнечик, Клавиатура, изометрический Робот не
  реализованы;
* цвет в Черепахе/Чертежнике — строка или число, а не отдельный тип
  `цвет` из `_Colorer`.
